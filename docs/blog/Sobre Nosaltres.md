## Qui som

Som l'Aaron Sánchez i en Sergi Sunyol, alumnes de segon d'ASIX (Administració de Sistemes Informàtics en Xarxa).

## Per què hem fet aquesta web

L'hem creat com a pràctica de classe per aprendre a escriure documentació tècnica amb MkDocs i publicar-la a GitHub Pages.

## Què hi trobaràs

La web té explicacions bàsiques sobre Linux, com els permisos i els usuaris i grups, i sobre serveis com SSH i HTTP. També hi ha una secció de xarxes amb DNS i TCP/IP, i un blog amb notícies i consells d'informàtica.

## Com està feta

Escrivim les pàgines en Markdown i MkDocs les converteix en una web. El codi és en un repositori de GitHub, i cada vegada que hi fem un canvi, GitHub Pages torna a publicar la web automàticament.
