**TCP/IP** és el conjunt de protocols que fa servir Internet per enviar dades d'un ordinador a un altre.

## Les capes

1. Accés a la xarxa: el cable o la wifi.
2. Internet: el protocol *IP* decideix per on van els paquets.
3. Transport: TCP i UDP.
4. Aplicació: HTTP, DNS, SSH...

![imatgeTCP-ip](https://www.checkpoint.com/es/wp-content/uploads/icon-tcp-ip.jpg)

## TCP i UDP

| | TCP | UDP |
|---|---|---|
| Comprova que arribin les dades | Sí | No |
| Exemple | Webs | Videotrucades |

## Comandes
```bash
ip a
ping 8.8.8.8
```
La primera mostra la teva IP i la segona comprova si hi ha connexió.
